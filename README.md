# Muhammad Adib Aulia Hanif — Portfolio CV

Personal portfolio / CV website built with pure HTML, CSS, and JavaScript.

## 🚀 Live at GitHub Pages

This site is deployed via GitHub Pages at:
`https://Muh-Adib.github.io/cv/`

## 📁 File Structure

```
cv/
├── index.html      # Main portfolio page
├── profile.jpg     # Profile photo (add your photo here!)
└── README.md
```

## 📸 Adding Profile Photo

Save your profile photo as `profile.jpg` in the root of this directory.

## 🛠 Setup GitHub Pages

1. Create a new repository on GitHub named `cv`
2. Push this folder to the repo
3. Go to **Settings → Pages → Source → Deploy from branch → main**
4. Your site will be live at: `https://Muh-Adib.github.io/cv/`
